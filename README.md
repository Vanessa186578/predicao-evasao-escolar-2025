# predicao-evasao-escolar-2025
A evasão escolar é um importante problema educacional que impacta estudantes e instituições de ensino. Este trabalho propõe o uso de Aprendizado de Máquina para prever a evasão escolar com base em dados acadêmicos e socioeducacionais
